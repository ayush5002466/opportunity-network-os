# Contributing

1. Open an issue describing the source, bug, or improvement before large changes.
2. Use a focused branch and a descriptive commit message.
3. Add or update tests for changed behavior.
4. Run `python -m compileall -q src tests` and `python -m unittest discover -s tests -v`.
5. Never commit `.env`, credentials, private application notes, or personal contact data.
6. Prefer official public job APIs and respect source terms and rate limits.
7. Do not add scraping of private contact details or mass-outreach automation.
